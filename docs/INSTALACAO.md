Bem-vindo ao guia oficial de instalação do **EasyQuiz**! Por se tratar de um *Bookmarklet* (um pequeno script salvo como favorito no seu navegador), a instalação leva menos de 10 segundos e não exige o download de extensões ou programas pesados.

## 📌 Passo a Passo de Instalação Rápida

1. **Abra seu Navegador** (Recomendamos Google Chrome, Brave, Edge ou Opera).
2. **Exiba a Barra de Favoritos**:
   - No Windows/Linux: Aperte `Ctrl + Shift + B`.
   - No Mac: Aperte `Cmd + Shift + B`.
3. **Crie o Favorito**:
   - Clique com o botão direito em um espaço vazio da Barra de Favoritos.
   - Escolha **"Adicionar página"** (ou "Adicionar favorito").
4. **Preencha os Campos**:
   - No campo **Nome**, digite: `EasyQuiz` (ou o nome que preferir).
   - No campo **URL** (ou "Endereço"), copie e cole um dos Códigos Oficiais fornecidos na página principal do projeto (Modo Legacy ou Modo Discreto).
5. **Pronto!** Salve o favorito.

Para utilizá-lo, basta acessar o site onde sua atividade ou quiz se encontra e **dar um clique no favorito que você acabou de criar**. O EasyQuiz será injetado imediatamente!

## 🔑 Como Obter Sua Chave da API (Totalmente Gratuita)

O EasyQuiz não possui servidores ou banco de dados próprios para processamento. Toda a mágica acontece diretamente entre o seu computador e os servidores do **Google Gemini**. Para isso, você precisa de uma "chave" de acesso.

1. Acesse o portal para desenvolvedores do Google: **[Google AI Studio](https://aistudio.google.com/app/apikey)**.
2. Faça login com sua conta do Google (a mesma que você já usa no Gmail ou YouTube).
3. Clique no botão azul gigante **"Create API Key"** (Criar chave de API).
4. O sistema irá gerar um texto longo (algo como `AIzaSyBw...`). **Copie esse texto**.
5. No **EasyQuiz**, clique na engrenagem de configurações ⚙️ (no Modo Legacy) ou pressione `Shift + A` (no Modo Discreto).
6. Cole a sua chave e salve!

> 🛡️ **Segurança em Primeiro Lugar:** Sua chave é salva exclusivamente no armazenamento local (`localStorage`) do seu navegador. Ela nunca é enviada para os criadores do EasyQuiz ou para terceiros.

## ❓ Perguntas Frequentes sobre Instalação

**Posso instalar no celular?**
R: A execução de bookmarklets em navegadores móveis é muito restrita e geralmente bloqueada pelas políticas de segurança. O uso do EasyQuiz é focado em ambientes Desktop/Notebooks.

**O código parou de funcionar do nada! O que eu faço?**
R: Os códigos que fornecemos apontam para a versão mais recente do projeto através de uma CDN (Rede de Distribuição). Se a sua internet oscilar e o código falhar, basta recarregar a página da prova (`F5`) e clicar no favorito novamente.

**Preciso atualizar meu favorito quando o EasyQuiz lançar uma nova versão?**
R: Não! Os códigos que você copia na página principal do nosso projeto já são desenhados para buscar as versões mais recentes da arquitetura. Você instala uma única vez e ele evolui para sempre.
