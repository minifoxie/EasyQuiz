Artigo Teórico • Contexto RAG Etapa 1 de 8

Matrizes Quadradas e o Cálculo de Determinantes (Regra de Sarrus)

Leia atentamente o artigo teórico a seguir antes de prosseguir para os exercícios práticos:

1. Estrutura de uma Matriz 3x3

Uma matriz quadrada de terceira ordem possui 3 linhas e 3 colunas, sendo representada por $A = (a_{ij})_{3 \times 3}$. Cada elemento é localizado pela linha $i$ e coluna $j$.

📌 Definição Fundamental: Uma matriz quadrada cujo determinante é estritamente igual a ZERO ($\det(A) = 0$) é chamada de Matriz Singular ou não invertível.

2. Regra de Sarrus

Para calcular o determinante de uma matriz $3 \times 3$, repete-se as duas primeiras colunas à direita da matriz e realiza-se a soma dos produtos da diagonal principal menos a soma dos produtos da diagonal secundária:

det(A) = (a11·a22·a33 + a12·a23·a31 + a13·a21·a32) - (a13·a22·a31 + a11·a23·a32 + a12·a21·a33)

A absorção correta desses conceitos é indispensável para a resolução dos sistemas lineares e matrizes dos próximos exercícios.

Sistemas Lineares • Verdadeiro ou Falso Questão 7 de 8

Julgamento de Itens sobre Sistemas Lineares e Matrizes

Julgue cada uma das afirmações teóricas abaixo como Verdadeira (V) ou Falsa (F):

Afirmação Julgamento
1. Todo sistema linear homogêneo (termos independentes nulos) admite pelo menos a solução trivial (0, 0, ..., 0).
2. Pela Regra de Cramer, quando o determinante principal D = 0 e algum determinante secundário D_x ≠ 0, o sistema é Possível e Determinado (SPD).
3. Se uma matriz quadrada possui duas linhas idênticas ou proporcionais, seu determinante é obrigatoriamente igual a zero.
4. Multiplicar uma única linha de uma matriz 3x3 por uma constante real k faz com que o determinante da nova matriz seja multiplicado por k³.
