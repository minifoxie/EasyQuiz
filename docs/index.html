Como usar o Modo Discreto

Fluxo de execução direto através de atalhos rápidos.

1

Ativação do Favorito

Abra a página da prova ou quiz e clique no favorito instalado. O script inicia silenciosamente em segundo plano.

2

Configuração Central de Chaves: Shift + A

Pressione as teclas para abrir o menu rápido. Cole sua chave do Google AI Studio. As chaves ficam salvas centralizadamente no navegador e funcionam em ambos os modos.

3

Resolver Questão: Shift + Q

Clique sobre a questão atual e dispare o atalho. O EasyQuiz realiza a leitura da pergunta e solicita a resolução.

4

Preenchimento de Respostas

Em questões escritas, toque qualquer tecla do teclado para que o script digite a resposta com cadência humana. Em múltipla escolha, a alternativa certa é marcada.

Tabela de Comandos de Teclado (Modo Discreto)

Atalhos padronizados para navegação em navegadores Chromium (Chrome e Edge):

Atalho Ação Executada
Shift+Q Escanear & Resolver: Analisa a questão selecionada e obtém a resposta da IA.
Shift+A Gerenciador de Chaves: Abre o menu para adicionar ou gerenciar chaves API.
Shift+Z Abortar / Pânico: Interrompe qualquer digitação ou requisição de rede em andamento.
Shift+R Recarregar IA: Repete a leitura e o envio caso haja instabilidade.
Shift+M Alternar Modelo: Alterna entre as versões disponíveis (Gemini Flash / Pro).
Shift+V Auditoria de Visão: Amostra a captura feita para fórmulas e imagens.

Como usar o Modo Legacy

O painel flutuante abre com os atalhos Alt + A ou Alt + Q.

1

Execução inicial

Na página da prova ou atividade, clique no favorito do Modo Legacy. O script será carregado em memória.

2

Abrir a Interface (Alt + A ou Alt + Q)

O painel lateral HUD deslizará para a tela. Você pode arrastá-lo e fixá-lo na lateral desejada.

3

Resolver Questão Atual

Clique no botão principal de resolução. O sistema marca o bloco com maior pontuação e calcula a resposta.

4

Auditoria e Injeção

Acompanhe o raciocínio na aba Cérebro, verifique imagens na aba Mídia e utilize o botão de injeção automática.

Painel Visual e Auditoria

O Modo Legacy é indicado para quem deseja controle visual minucioso de cada etapa da resolução.

Ele inclui abas dedicadas para:

  • Principal: Resultado direto da questão e botão para aplicação automática.
  • Cérebro: Leitura completa do passo a passo gerado pelo modelo antes da resposta final.
  • Mídia: Visualização da foto/recorte da tela capturado para gráficos e matemática.
  • Terminal: Telemetria detalhada de eventos despachados no navegador.
  • Configurações: Gerenciamento das chaves de API unificadas e troca de modelos.

Guia de Configuração de Chaves API

As chaves de API conectam o EasyQuiz diretamente aos modelos do Google Gemini. O acesso inicial é gratuito e a configuração é feita uma única vez.

1

Acessar o Google AI Studio

Acesse o portal oficial de desenvolvedores do Google para gerenciamento de chaves Gemini.

Abrir Google AI Studio
2

Criar a Chave de Acesso

Clique no botão Create API Key no canto superior. Selecione um projeto ou crie um novo projeto com um clique.

3

Copiar a Chave Gerada

A chave começa com o prefixo AIzaSy.... Copie o código gerado para a sua área de transferência.

4

Cadastrar no EasyQuiz

• No Modo Discreto: Tecle Shift + A e cole a chave.
• No Modo Legacy: Abra o painel com Alt + A ou Alt + Q e acerte na aba de engrenagem.

Importante: As chaves são centralizadas. Cadastrando em um modo, o outro modo reconhece instantaneamente.

5

RECOMENDAÇÃO: Cadastre Múltiplas Chaves de API

Para obter estabilidade máxima e zero pausas por limite de taxa, cadastre 2 ou mais chaves de contas diferentes do Google. O EasyQuiz alterna e balanceia as chaves de forma 100% automática a cada questão.

Basta colar uma chave por linha no gerenciador de chaves.
