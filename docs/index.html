Como Usar

Painel abre com Alt+A ou Alt+Q

01

Executar o Favorito

Na página do quiz, clique no favorito. Script carrega em memória.

02

Abrir Painel Alt+A

O painel HUD desliza para a tela. Pode ser arrastado e fixado.

03

Resolver Questão

Clique no botão principal. O sistema calcula a resposta com maior pontuação.

04

Auditoria e Injeção

Cérebro, Mídia, Terminal e Configurações estão acessíveis pelas abas.

Como obter sua chave de API

Acesso gratuito ao Google Gemini. Configuração feita uma única vez.

01

Acessar o Google AI Studio

Portal oficial para gerenciar chaves Gemini.

Abrir Google AI Studio
02

Criar a Chave

Clique em Create API Key. Selecione ou crie um projeto.

03

Copiar o Token

A chave começa com AIzaSy.... Copie para a área de transferência.

04

Cadastrar no EasyQuiz

Discreto: Shift+A → cole a chave.
Legacy: Alt+A → aba de engrenagem.

As chaves são centralizadas. Um modo reconhece o outro automaticamente.

05

Recomendação: Múltiplas Chaves

Cadastre 2 ou mais chaves de contas diferentes para velocidade máxima e zero bloqueios. O EasyQuiz balancea automaticamente.
