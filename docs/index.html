Como Iniciar

Exiba a Barra de Favoritos (Ctrl+Shift+B).

Arraste o botão acima para sua barra. O nome será salvo como EQ Discret.

Na página do quiz, clique no favorito. Nada mudará visualmente, mas o script estará vivo na memória.

Pressione Shift+A para configurar sua chave de API do Gemini e começar a resolver.

Event Hooking Furtivo

Quando a IA obtém a resposta, o Discreto espera você pressionar qualquer tecla na prova. Ao digitar, ele anula sua letra e simula uma digitação humana instantânea injetando a resposta correta via isTrusted: true.

Tabela de Comandos de Batalha (Atalhos)

Shift+QEscanear: Ativa o robô para ler a questão focada e enviar para a IA.
Shift+ZAbort / Panic: Cancela digitação em andamento e mata a requisição pendente.
Shift+RRecarregar IA: Força a IA a ler a questão de novo se der timeout.
Shift+AMenu de API: Abre o popup translúcido no rodapé para você gerenciar múltiplas chaves.
Shift+MTrocar Cérebro: Alterna entre Gemini Flash, Pro, etc.
Shift+VAuditoria de Visão: Pisca rapidamente como a IA enxergou as fórmulas/imagens da tela.

Arrastar para favoritos

Como Iniciar

Exiba a Barra de Favoritos (Ctrl+Shift+B).

Arraste o botão acima para sua barra. O nome será salvo como EQ Legacy.

Na página da prova, clique no favorito. O script carregará de forma oculta.

Pressione Alt+Q (ou Alt+A) para que a janela HUD flutuante deslize para dentro da sua tela.

O Botão "Resolver"

Ao clicar no botão verde principal do painel, o sistema escaneará o "Ponto de Foco", traçará uma linha verde ao redor da questão e iniciará o scrape semântico avançado para enviar ao Gemini.

Abas do Painel HUD

PrincipalOnde a IA mostra o resultado final. Use Injetar Resposta para preencher automaticamente ou Limpar para analisar outra questão.
CérebroChain of Thought: Exibe o raciocínio interno, planejamento e discussão da IA passo-a-passo antes de definir a resposta certa.
MídiaVisão Computacional: Mostra o screenshot bruto tirado da tela (útil para verificar fórmulas matemáticas e gráficos interativos).
TerminalPainel de telemetria para programadores. Registra logs de DOM Injections e PointerEvent Overrides em tempo real.
EngrenagemConfigurações: Onde você insere suas chaves de API, muda os modelos da IA e configura limiares de detecção.

Como obter sua chave de API

O cérebro do EasyQuiz roda via Google Gemini. A configuração leva 1 minuto.

01

Acesse o Google AI Studio

O painel de desenvolvedores do Google fornece as chaves.

Abrir Google AI Studio
02

Crie a Chave (Create API Key)

Escolha criar num novo projeto. Ela começará sempre com AIzaSy...

03

Cadastre no EasyQuiz

Abra o menu (Shift+A no Discreto, aba Config no Legacy) e cole.

Chaves são compartilhadas entre os modos.
★

Recomendação Multi-Key

Cole várias chaves em linhas diferentes para evitar limites de uso grátis e garantir velocidade máxima.
