O que torna o EasyQuiz diferente

Tecnologias de engenharia avançada embutidas em um único script de bookmarklet.

Detecção Semântica Cega

Não depende de seletores CSS frágeis. O motor varre a Árvore DOM procurando padrões estruturais de questões em qualquer plataforma.

Digitação Humanizada

Preenchimento de respostas através de eventos de teclado com intervalos randômicos, simulando digitação humana e contornando defesas de frameworks.

Multi-Key Inteligente

Cadastre múltiplas chaves API do Gemini com balanceamento automático de carga, rotação em caso de limite e zero lentidão.

Shadow DOM Encapsulado

Toda a interface do Modo Legacy reside em um Shadow DOM estritamente isolado, inacessível aos scripts da página hospedeira.

Visão Computacional

Para fórmulas matemáticas e elementos Canvas, o sistema captura uma imagem da área e envia para a IA analisar visualmente.

Raciocínio Passo a Passo

A IA é orientada a estruturar o raciocínio antes de emitir a resposta definitiva, prevenindo alucinações e garantindo precisão.

Engenharia em Detalhes

Como funciona o ecossistema técnico por baixo do capô.

Engenharia Reversa de DOM

Em vez de procurar por classes específicas (que mudam a cada atualização das plataformas), varremos a árvore procurando blocos com assinatura de questão. O elemento com maior correspondência é selecionado como a questão ativa.

Compatibilidade com React, Vue e Angular

Formulários modernos ignoram alterações diretas de input.value. O script despacha PointerEvent e KeyboardEvent sintéticos com coordenadas reais e atualiza o rastreador de estado interno dos componentes.

Como operar o Modo Discreto

Comandos disparados discretamente por combinações de teclas.

1

Instale e ative o favorito

Com o bookmarklet salvo na barra de favoritos, acesse a página da prova e clique nele. Nada mudará visualmente na tela — o script estará ativo em segundo plano.

2

Configure sua API Key com Shift+A

Pressione a combinação de teclas para abrir o menu rápido de chave API. Cole a chave do Google AI Studio. A configuração fica salva no seu navegador.

3

Resolva a questão com Shift+Q

Clique sobre a questão desejada e pressione o atalho. O script analisa o enunciado e as opções, enviando para a IA.

4

Preenchimento humanizado

Em questões dissertativas, pressione qualquer tecla do teclado para que o script digite a resposta correta de forma natural. Em múltipla escolha, a alternativa certa é selecionada.

⌨️ Tabela de Atalhos do Modo Discreto

Todos os comandos do Modo Discreto são operados por teclas de atalho:

Atalho Ação
Shift+Q Escanear & Resolver: Analisa a questão ativa e solicita a resposta para a IA.
Shift+A Gerenciador de API: Abre o mini-modal translúcido para cadastrar ou alternar chaves.
Shift+Z Abort / Pânico: Cancela imediatamente qualquer requisição ou digitação em andamento.
Shift+R Recarregar IA: Força nova leitura da questão caso ocorra timeout ou instabilidade de rede.
Shift+M Alternar Modelo: Alterna entre as versões do Gemini (Flash / Pro).
Shift+V Auditoria de Visão: Exibe por instantes a captura feita da tela para fórmulas e gráficos.

Como usar o Modo Legacy

O painel visual é aberto e fechado pelo atalho Alt+Q.

1

Instale e execute o favorito

Salve o código acima nos favoritos do navegador. Acesse a plataforma da prova e clique no favorito instalado.

2

Abra o Painel com Alt+Q

O painel flutuante deslizará para dentro da tela. Clique na aba de engrenagem para configurar sua chave API do Google.

3

Clique em Resolver Questão

Clique no botão principal. A IA analisará o bloco detectado e apresentará a resposta calculada na tela.

4

Audite o raciocínio ou injete

Você pode ler o raciocínio completo da IA na aba Cérebro, conferir as capturas na aba Mídia ou clicar em Injetar Resposta.

💻 Modo Legacy: Auditoria Visual Completa

O Modo Legacy (Modo Painel) foi projetado para quem prefere controle visual total e transparência absoluta do que a inteligência artificial está processando.

Ele injeta uma janela flutuante arrastável através de Shadow DOM encapsulado, mantendo o isolamento contra detecções da página hospedeira.

🛠️ Abas do Painel

  • Principal: Exibe a resposta final calculada e o botão para injeção automática no formulário.
  • Cérebro (Chain of Thought): Onde você acompanha todo o raciocínio analítico da IA antes da resposta.
  • Mídia: Amostra a imagem capturada da questão para conferência visual em fórmulas matemáticas e gráficos.
  • Terminal: Telemetria em tempo real das injeções de eventos e respostas da API.
  • Configurações: Gerenciador de chaves API, seleção de modelos e ajuste de sensibilidade de detecção.

Como obter sua API Key

A chave de API conecta o EasyQuiz à IA do Google Gemini. É 100% gratuita e leva menos de 2 minutos para configurar.

Privacidade total: Sua API Key nunca sai do seu navegador. O EasyQuiz não tem servidor. Todas as requisições partem do seu próprio navegador diretamente para a API do Google.

1

Acesse o Google AI Studio

O Google AI Studio é a plataforma oficial do Google para desenvolvedores. O plano gratuito oferece cotas generosas sem necessidade de cartão de crédito.

Abrir Google AI Studio
2

Crie uma nova chave

Na aba de API Keys, clique no botão azul "Create API Key". Escolha um projeto existente ou crie um novo com apenas um clique.

3

Copie o código gerado

A chave gerada começa com AIzaSy.... Clique no ícone de cópia ao lado dela para copiá-la para a sua área de transferência.

4

Cole no EasyQuiz

Com o bookmarklet ativo em qualquer página:

• Modo Discreto: Pressione Shift+A → cole a chave e confirme.
• Modo Legacy: Abra o painel com Alt+Q → clique na engrenagem → cole a chave.

5

(Opcional) Cadastre Múltiplas Chaves

Para evitar pausas por limite de taxa da API gratuita, cadastre 2 ou mais chaves de contas diferentes. O EasyQuiz fará o balanceamento automático de carga.
